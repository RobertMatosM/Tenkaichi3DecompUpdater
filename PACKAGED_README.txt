Tenkaichi3Decomp Updater
=======================

This portable package contains the graphical updater. No Python installation is
required to run it.
See LICENSE.txt for license terms.

Windows: launch Tenkaichi3DecompUpdater.exe from this folder.
Linux: launch Tenkaichi3DecompUpdater from this folder.

The updater needs an internet connection to check for and download releases.
Close the game and its setup window before updating an existing Windows install.

For help or to report a problem, visit:
https://github.com/RobertMatosM/Tenkaichi3DecompUpdater
